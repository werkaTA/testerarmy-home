In your CI job

One command in your workflow runs the tests after deploy and writes the result to a file.

A GitHub Actions workflow that installs the TesterArmy CLI and runs ta ci after a deployment.
.github/workflows/testerarmy.yml
name: Run TesterArmy after deploy
on: deployment_status
jobs:
test:
runs-on: ubuntu-latest
steps:
- run: npm install -g testerarmy
- run: ta auth --api-key $TESTERARMY_API_KEY
- run: ta ci --output .testerarmy/ci-result.json
